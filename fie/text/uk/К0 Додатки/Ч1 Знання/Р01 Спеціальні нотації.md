Спеціальні нотації

У тексті використовуються різні позначення для того, щоб відобразити ту чи

іншу сторону описуваних подій. Їх можна розділити на три категорії:

Позначення тексту:

➔ Червона поні з'явився з тіней.

// Стандартний текст, який використовується в описовому контексті або коли інші позначення не застосовуються.

➔ …а як ще можна думати про це?.. відображає який

Блок,

// думки персонажа. Його можна використовувати в діалоговому контексті, якщо суб'єкти здатні до ментального спілкування.

➔ “Питання, відповіді на які ви не хочете знати…”

// Спеціальні рядки, які не стосуються конкретних персонажів і служать для логічного поділу всередині глави.

➔ Пффт, “сказаний”.

// Виділення фрагментів тексту або для посилення підтексту, або для вказівки на непряму мову.

Позначення діалогу:

➔ [Фс] – Ви ж поняття не маєте, що я таке.

// Пряма репліка персонажа без додаткових описів (характер і персонаж можна визначити або з контексту, або з префікса).

➔ Як це можна зробити? — вигукнула Твайлайт. — Це проти природи поні! Прямий рядок з додатковою інформацією або про контекст, або про персонажа.

➔ [Тс] — Ха, це те, що ви називаєте магією, — засміялася вона, — машина

ніколи не замінить живої душі. // Пряма репліка з додатковою інформацією або про контекст, або про персонажа.

➔ [Зе] –

Зовнішність часто оманливою буває, Особливо, якщо темрява очі затуляє. // Римована пряма мова.

➔ Префікси мають формат [**] –, де замість зірочок використовується код

імені, який визначається як:

◆ Перші літери частин звичайного імені в нотації земних поні (нова).

Приклади: Твайлайт Спаркл – Тс, Шадоу Мунлайт – Мш.

◆ Перші дві літери неоімені (односкладові). Приклади: Раріті - Ра,

Зекора - Зе.

◆ Більшість кодів імен персонажів, що використовуються в тексті,

можна переглянути в глосарії персонажів.
